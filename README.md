# Retailrocket 历史行为分析

基于真实 Retailrocket 历史数据，在三节点 Kafka / HDFS / YARN 上完成回放、Spark 持续处理与历史分析，通过 React 看板演示。**V1、V2 均已完成并验收。** 这是历史数据回放，不代表真实用户此刻访问；业务日期统一使用 UTC。

## 启动演示

**推荐答辩入口：全量历史图表＋实时回放控制**：

```bash
./demo --full-history
```

等终端显示“演示已就绪”，打开 **http://127.0.0.1:5173**，历史分析直接展示已验收的 **2,756,101 条**全量结果。首次启动复制独立展示副本，并启动既有集群和实时控制；小样本回放发布不会覆盖全量图表。结束运行 **`./demo stop`**。

无需集群、只展示图表时使用 **`./demo --full-history --history-only`**，退出按 Ctrl+C。普通 **`./demo`** 仍按最近成功发布的回放结果展示历史。入口共用端口，不能同时启动。

## 答辩时怎么演示

1. 启动固定小样本，速率 **5 条/秒**，等待 Spark 就绪时先讲历史分析。
2. 展示行为概览、购买关联、分类偏好、用户画像与数据质量。
3. 回到实时监控，观察消息、积压、业务统计；演示**暂停 → 继续 → 提前停止**。
4. 结束时另开终端运行 **`./demo stop`**，自动停止回放、排空、关闭服务和项目虚拟机。

全量历史有 **2,756,101 条事件**；正常小样本负载持续约 15 分钟的可见延迟 P95 保守上界为 **8.58 秒**。完整自动发布和跨节点执行已有真实验收证据，答辩现场无需重新跑全量。
