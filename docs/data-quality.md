# 行为数据质量

清洗按数据版本、源文件和过滤前源行号去重采集重试消息，保留不同源行中的相同内容。
疑似重复是相同事件字段的额外源记录数，与有效/异常数量重叠，不作为剔除项扣减。
原始消息保存在 raw，异常源字段及首个校验失败原因保存在 quarantine。

事件时间按 UTC epoch 毫秒解析，支持公历 0001-01-01 00:00:00.000 至
9999-12-31 23:59:59.999 UTC（闭区间）；无法解析或越界的时间隔离为
invalid_timestamp，避免算术溢出及导出日期范围错误。其他首个失败原因依次为
missing_visitor、missing_item、invalid_event。浏览和加购的空交易标识合法。

数据质量页的原因统计和记录查看默认覆盖整个批次，包含时间无效的异常。
切换到所选 UTC 日期时只包含可归属该日期范围的记录，时间无效记录不会被误记入
某一天。原因统计覆盖全部匹配异常，记录视图按版本、文件、行号排序，最多显示
500 条。没有有效事件的批次仍可查看全批次异常原因和原始字段。
