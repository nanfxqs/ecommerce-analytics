# V2 采用有界回放与分阶段流批处理

V2 对确定范围的 Retailrocket 历史数据进行单轮回放，以 YARN 上的 Spark Structured Streaming 持续处理，检查点保存在 HDFS；每轮精确去重并接纳合法乱序事件。相比无限循环和按迟到阈值丢弃事件，这样能保持与 V1 相同输入范围的指标可核对，代价是需要保留本轮去重状态，并在资源受限时降低回放速率。

既有集群资源有限，正常回放结束并处理完积压后，先保存最终实时结果并释放流任务资源，再运行完整历史批处理；不并行运行两个 Spark 作业。历史分析通过校验才切换发布，失败保留此前成功结果；提前停止的轮次不自动发布历史结果。该方案延后了完整历史结果的可用时间，但保留 V1 的可靠发布边界，避免为实时展示放宽完整性要求。

本决策扩展 ADR 0002 的 V1 手动批处理边界，不改变其对 V1 的适用性。用户已于 2026-10-19 确认上述取舍；实现前仍须验证流处理状态、恢复与资源占用。
